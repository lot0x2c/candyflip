candy & candy flip

candy and candy flip are a simple pair of pink/teal base16 themes for Emacs.

Motivation

I wanted a pink and teal theme for Emacs that comes as a light and dark pair with matching colors. base16-theme already generates the faces for hundreds of packages, so each theme here is only a palette of 16 colors plus a few overrides.

Status

Things that have already been implemented are:

  • light theme (candy)
  • dark theme (candy flip)
  • 16 colors per theme, defined in one place
  • faces generated by base16-theme
  • region drawn with inverse-video, so it works with any foreground
  • org-level-3 override in candy flip
  • pink or teal accent
  • low, normal and high contrast
  • inverse or base02 region
  • flat or boxed mode line
  • transparent background in terminals
  • bold, italic and underline per token type
  • candy-toggle command
  • no dependencies other than base16-theme

Examples

Elisp and C in both themes. Colors follow base16-theme's font-lock faces: keyword is base0E, string base0B, function base0D, type base0A, constant base09, variable base08, builtin base0C, comment base03.

Tick a box to try bold, italic or underline on a token type. The examples update, and the matching candy-formats setting is printed below the table.

Installation


Both themes need base16-theme.
Get a copy of the source:


git clone https://github.com/ro15rend/candy-theme


Add the checkout to custom-theme-load-path and load a theme:


(package-install 'base16-theme)
(add-to-list 'custom-theme-load-path "/path/to/candy-theme/")
(load-theme 'base16-candy t)   ; or 'base16-candy-flip


Doom Emacs, in packages.el:


(package! base16-theme)
(package! candy-theme
  :recipe (:host github :repo "ro15rend/candy-theme" :files ("*.el")))


and in config.el:


(setq doom-theme 'base16-candy)



Configuration


Options are set before load-theme. Changing them later with
setopt or M-x customize-group RET candy reloads
the enabled theme.




optionvaluesdefault


candy-accentpink, tealpink


candy-contrastlow, normal, highnormal


candy-region-styleinverse, backgroundinverse


candy-mode-line-styleflat, boxedflat


candy-transparent-backgroundnil, tnil


candy-formatsalistnil




(setq candy-accent 'teal
      candy-contrast 'high
      candy-formats '((keyword bold) (comment italic)))
(load-theme 'base16-candy-flip t)


Transparency only applies to terminal frames. In graphical Emacs 29+ use
(set-frame-parameter nil 'alpha-background 90).


The palette is stored in base16-candy-theme-colors and
base16-candy-flip-theme-colors at the top of each theme file.
